# Axyom — Demo

A published copy of the Axyom demo: one self-contained `index.html`, example data
only, no backend and no network calls.

Served at **https://demo.axyom.ch** via GitHub Pages. The source lives in
`~/axyom-demo` (`parts/` + `build.sh`); this repository only carries the built
file, deployed with `~/axyom-demo/publish.sh`.
